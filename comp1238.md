## Week 1
- Data management involves collecting, organizing, storing, and retrieving information.
- Structured data can be organized into tables with rows and columns.

## Week 2
- A database stores related data in an organized format.
- A database management system (DBMS) helps users create, update, and query databases.

## Week 3
- A primary key uniquely identifies each record in a table.
- A foreign key connects records between related tables.

## Week 4
- SQL stands for Structured Query Language and is used to work with relational databases.
- The SELECT statement retrieves data, while WHERE filters records based on conditions.

## Week 5
- Data types specify what kind of values a column can store, such as numbers or text.
- Database normalization helps reduce duplicate data and improve consistency.
